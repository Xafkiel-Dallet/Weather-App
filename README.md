🌦️ Weather App

A simple and responsive weather application built with HTML, CSS, and JavaScript. It allows users to search for any city and instantly view the current weather conditions using a weather API.

✨ Features

- 🔍 Search weather by city name
- 🌡️ Displays current temperature
- ☁️ Shows weather condition and description
- 💧 Displays humidity
- 💨 Shows wind speed
- 📱 Fully responsive design
- ⚡ Fast and lightweight

🛠️ Built With

- HTML
- CSS
- JavaScript
- Weather API
